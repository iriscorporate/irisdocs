This documentation lists the history of the main changes that have been implemented since version 16.0.0.

For each version, the following **sections** are given:

* New features / `Added`
* Improvements / `Changed`
* Deprecated or removed features
* Added or removed resources
* Fixed bugs
* Known issues

This is a change log. For any **further details**, refer to the **API REF** (.chm file)

Operating systems

* Windows (x86, x64, ARM64)
* Linux (x86, x86-64, ARM32, ARM64, MontaVista CGE6, MontaVista CGX2)
* macOS (x86\_64, ARM64)
* Android (armeabi-v7a, arm64-v8a)
* iOS (arm64, x86\_64)
