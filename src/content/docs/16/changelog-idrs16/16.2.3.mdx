## `Improvements`

### Allow transparent images while signing a PDF

When signing a PDF with a visible signature, you can add a transparency mask to the background image.  
You can set this mask, simply by calling the new method `SetTransparencyMask()` from `CPageZoneGraphicExternalImage`.

### Loading Jpeg Image with CMYK pixel format

The JPEG images with CMYK pixels can now be loaded by iDRS.
