Welcome to the **IRISOCR™ SDK Documentation**  
(also referred to as [iDRS™](glossary/glossary.html#iDRS)).

## Documentation Structure

This documentation has five key sections:

* **Specifications**: This section gives all important technical specifications.
* **Change Log**: This section shows the main changes since version 16.0.0. It also serves as **Release notes**.
* **Developer Guide**: This section describes selected features and how they work.
* **API Reference**: This section gives detailed information about classes, methods, and properties.
* **Glossary**: This section lists acronyms and important terms.
