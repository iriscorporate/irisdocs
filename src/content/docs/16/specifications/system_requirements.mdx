## System requirements of the latest release

**Minimum** requirements are:

Table 1. System Requirements (applies to the latest released version)

| Platform | CPU | OS | .NET version4 | C++ Standard |
| --- | --- | --- | --- | --- |
| **Windows** | x86, x64, ARM64 | Windows 10 or higher | .NET framework 4.8 or higher  .NET 6 or higher | C++14 or higher |
| **Linux** | x86, x86-64, ARM, ARM64 | glibc version equal or greater than 2.28 | .NET 6 or higher |
| **macOS** | x86\_64, ARM64 | macOS 10.13 or higher |
| **Android** 1,3 | x86, x86-64, ARM, ARM64 | OS compatible with API level 21  this is the case for Android version 5.0 Lollipop and higher | N/A |
| **iOS** 2,3 | ARM64, x86\_64 | 11 or higher | N/A |

1 The sample applications delivered with the software can be built and executed using **Android Studio application**.  
2 The sample applications delivered with the software can be built and executed using **Xcode** 14 or higher versions.  
3 **The sample applications require a camera.**  
4 The .NET requirement is only necessary for integrators using the .NET API.
