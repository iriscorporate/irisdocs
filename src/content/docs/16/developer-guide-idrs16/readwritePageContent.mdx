---
title: "Read/Write access to page content"
---

You can **read/edit** the page content via the class `CPage::GetPageContent()`

**Editing** a page content includes:

* layout information (sections, text columns, zones,…​)
* text (lines, words, characters)
* style (font family, font size, …​)

Two useful **business cases** would be:

* The correction of OCR results before creating the output document
* The creation of a page and its content from scratch
