## I.R.I.S. Hyper compression (iHQC)

### What is it?

iHQC stands for **intelligent High-Quality Compression**. It is a I.R.I.S proprietary implementation of mixed raster content compression method (MRC). It relies on image segmentation to fine-tune the compression rate applied to input images.

iHQC mode uses several compression algorithms: JPEG, JPEG2000, TIFF and JBIG2.

To use **iHQC** mode, use the `PageDisplay::HyperCompression` **Option**.  
To set the **hypercompression algorithms**, use the `CPdfCompressionOptions` **Class** and set the Bitonal and Color formats.  
The **bitonal algorithm** compresses the text layer and black and white documents. The **color algorithm** compresses the background and foreground layers on color and grayscale documents.
